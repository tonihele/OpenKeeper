NativeRamps.bin contains DKII's gamma-1 channel tables for effect IDs 0..15:
16 effects × 256 entries × three unsigned little-endian 16-bit channels (RGB).
These are numerical lookup tables, not texture artwork. They were generated by
executing the original DKII.exe ramp builder at 0x597760 in an isolated harness.

The original switch table at 0x598034 maps IDs to their handlers. Effect 3
(Skeleton) is blue-biased, despite its BLACK_N_WHITE enum name. At input 128
it returns RGB (16383, 16383, 49151). ID 16 (Ghost) has no handler and leaves
the previous destination unchanged; it is not included as an invented preset.

The tables assume gamma 1. OpenKeeper's sRGB rendering option is handled at the
framebuffer boundary; this does not introduce a separate native gamma slider.
Possession camera transitions retain their existing timing. Native transition
interpolation and temporary status-driven effects require further integration.
